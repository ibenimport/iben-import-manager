🔍 Aperçu de l'import
💡 Aide — Format du fichier CSV
Colonnes obligatoires : Référence, Désignation, Famille
Colonnes optionnelles : Sous-famille, Couleur, Taille, Longueur rouleau, Prix achat HT, Prix vente HT, Unité, TVA, Alerte stock

Familles disponibles : Verre, Céramique, Métal, Emballage, Ruban, Mercerie/Textile
Unités : Pièce, Kg, Mètre, Rouleau
TVA : 0, 7, 10, 20

Règles :
  • Si une référence existe déjà dans votre catalogue, le produit est ignoré (pas de doublon).
  • Si une sous-famille n'existe pas, elle est créée automatiquement.
  • Les valeurs vides (prix, alerte...) sont mises à 0 par défaut.
  • Les décimales acceptent les , ou les . (ex: 15,50 ou 15.50).
  • Le séparateur peut être ; (Excel français) ou , (Excel anglais).
